# Mini Delicias — sitio web

Sitio estático para el emprendimiento escolar Mini Delicias, desarrollado con HTML5, CSS3 y JavaScript. No requiere instalación, servidor ni dependencias.

## Vista previa local

1. Descomprimí `mini-delicias-web.zip`.
2. Abrí la carpeta `mini-delicias-web`.
3. Hacé doble clic en `index.html` para abrir el sitio en el navegador.

## Publicación gratuita en GitHub Pages

1. Iniciá sesión en GitHub y creá un repositorio **público** llamado `mini-delicias`.
2. Subí al repositorio todos los archivos y carpetas que están dentro de `mini-delicias-web` (el archivo `index.html` debe quedar en la raíz del repositorio).
3. Entrá en **Settings**.
4. En el menú lateral, seleccioná **Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**.
6. En **Branch**, seleccioná `main` y la carpeta `/(root)` (root).
7. Presioná **Save**.
8. Esperá a que GitHub Pages publique el sitio. El enlace aparecerá en la misma sección de Pages y tendrá un formato similar a `https://TU-USUARIO.github.io/mini-delicias/`.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: identidad visual, diseño responsive y animaciones.
- `script.js`: menú móvil, ventanas de producto, galería y enlaces de consulta.
- `assets/`: logotipo y fotografías originales extraídas del PDF proporcionado, más recortes de detalle para la galería.

## Antes de publicar

- La dirección particular fue omitida por privacidad. El sitio muestra “Consultar ubicación y punto de entrega”.
- Los medios de pago figuran como “Consultar medios de pago”.
- Confirmá que el teléfono, correo y precios continúen vigentes.
- Las fotografías de detalle de la galería son recortes de las fotografías originales incluidas en el PDF.
- El sitio utiliza Google Fonts si hay conexión a Internet; si no, se muestran tipografías alternativas del sistema.
